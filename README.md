# 🤖 ECHO — issue tracker

Bug reports and ideas for **ECHO**, the AI buddy with a jetpack for Minecraft (Fabric 1.21.1).

📦 **Download:** [modrinth.com/mod/echo-ai-buddy](https://modrinth.com/mod/echo-ai-buddy)

### 🐞 Found a bug?
[Open a bug report](../../issues/new?template=bug_report.yml). Please attach your `latest.log` (in `.minecraft/logs`).

### 💡 Got an idea?
[Suggest a feature](../../issues/new?template=idea.yml).

### Before you post
- Search the [open issues](../../issues) first, your bug may already be there.
- ECHO's logs keep no speech and no API key, but they can show your username and folder paths. Remove anything you don't want public.
- **Never post your Gemini API key.**
